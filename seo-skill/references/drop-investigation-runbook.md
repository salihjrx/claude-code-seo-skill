# Organic Traffic / Ranking Drop Runbook

1. Establish exact dates, affected market, device, query and page groups.
2. Verify analytics tagging and consent changes before interpreting traffic.
3. Separate impressions, clicks, CTR, average position, organic sessions and conversions.
4. Compare brand/non-brand, country, device, page type and query intent.
5. Check deployment history, HTTP errors, robots/noindex, canonical changes, rendering, sitemap, internal links, redirects, security/manual actions and log patterns.
6. Review demand seasonality, SERP feature changes, competitor launches and content freshness.
7. Compare affected and unaffected cohorts.
8. Form ranked hypotheses with confidence and tests.
9. Apply the smallest reversible fix; document release and monitor.
10. Do not call a cause confirmed until evidence supports it. Do not claim an algorithm penalty without evidence.
