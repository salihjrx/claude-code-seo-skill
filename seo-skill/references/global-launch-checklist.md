# Global SEO Launch Checklist

## Technical
- [ ] Production host, HTTPS, redirects and status codes verified.
- [ ] Robots/noindex rules checked in production.
- [ ] Canonicals, sitemap, internal links and redirects agree.
- [ ] Important content renders and key links are crawlable.
- [ ] Error pages return correct status codes.
- [ ] Structured data is valid and matches visible content.

## International
- [ ] Market/language matrix approved.
- [ ] Locale URLs and language switcher work.
- [ ] Hreflang is valid, reciprocal and canonical-consistent.
- [ ] Localized copy, prices, shipping, returns and support are accurate.
- [ ] No forced geo redirects or thin duplicate locale pages.

## Content and commerce
- [ ] Each important URL maps to a clear intent.
- [ ] Product/category pages provide distinct, accurate value.
- [ ] No fake reviews, prices, stock, credentials or claims.
- [ ] Internal links and navigation expose priority pages.

## Measurement
- [ ] Search Console/Bing tools configured where authorized.
- [ ] Analytics and conversion events tested.
- [ ] Baseline recorded by market, device and page type.
- [ ] Post-launch monitoring owner and escalation path defined.

## Release evidence
Record URL samples, test tools, date, actual outcomes, failures and items that could not be verified.
