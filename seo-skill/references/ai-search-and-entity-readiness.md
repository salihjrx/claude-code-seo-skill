# AI Search and Entity Readiness

This is a measurement and content clarity playbook, not a claim that there is one universal “GEO ranking factor”.

## Practical foundations
- Make pages crawlable and index-eligible when appropriate.
- Provide clear entity names, definitions, ownership, product/service details and source-backed claims.
- Publish original evidence, useful comparisons, methods, limitations and maintained reference material.
- Keep organization identity consistent across the website and trustworthy external profiles.
- Use descriptive headings, semantic HTML, tables/lists where they improve comprehension, and explicit source attribution.
- Avoid unsupported claims that a special file, schema type, keyword density or prompt trick guarantees AI citations.

## Measurement
Where supported, track referral traffic, landing pages, citations/mentions, branded query trends and qualified conversions. Save dated query/prompt samples and note that answers vary by location, account, model and time. A manual sample is directional, not a representative market-share study.

## Evaluation protocol
Use a fixed test set of user questions, markets and dates; define what counts as a correct mention/citation; compare against a baseline; log source URLs and errors; repeat tests; disclose sampling limits. Never fabricate citation share or imply a platform has a documented ranking formula without official evidence.
