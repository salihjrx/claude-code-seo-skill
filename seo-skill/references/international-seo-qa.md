# International SEO QA

- [ ] Each locale has a stable, crawlable URL.
- [ ] Visible page content is genuinely localized.
- [ ] Language and regional codes are valid.
- [ ] Hreflang pages are equivalent alternatives, reciprocal and self-referencing.
- [ ] Canonical tags do not conflict with localized variants.
- [ ] Sitemap and internal links use intended canonical locale URLs.
- [ ] Currency, shipping, taxes, returns, units, dates and support are locale-appropriate.
- [ ] Language switcher uses crawlable links and is accessible.
- [ ] No forced geo/IP redirect prevents access to alternatives.
- [ ] Locale pages are not thin city/country swaps.
- [ ] Each market's indexability and conversion tracking can be segmented.
- [ ] Check rendered HTML and deployed response, not only source templates.
